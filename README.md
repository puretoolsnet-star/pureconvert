# PureConvert

Client-side unit converter for [convert.kixt.net](https://convert.kixt.net), part of the kixt.net ecosystem.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3010](http://localhost:3010).

## Build

```bash
npm run build
npm start
```

## Environment

Copy `.env.example` to `.env.local` for production URLs.
